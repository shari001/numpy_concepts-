# NumPy Practice

This section contains Jupyter Notebooks where I practiced core concepts of **NumPy**, the fundamental package for numerical computing in Python.

## 🔎 What is NumPy?
NumPy (Numerical Python) is a powerful library for:
- Working with arrays and matrices
- Performing mathematical and statistical operations
- Handling large datasets efficiently

It forms the foundation for many data science and machine learning workflows.

## 📚 Concepts Practiced
- Creating arrays (`np.array`, `np.zeros`, `np.ones`)
- Indexing and slicing
- Broadcasting rules
- Mathematical operations on arrays
- Aggregations (sum, mean, max, etc.)
- Reshaping and concatenation
- Random number generation
